# NÚCLEO

Es el centro común del sistema.

Responsabilidades:
- modelo de proyecto
- modelo semántico
- identidad de elementos
- unidades
- estados
- versiones
- issues
- aprobaciones
- trazabilidad
- configuración general
- contratos de datos entre módulos

Debe ser independiente de AutoCAD, Revit, ETABS, SAFE y SAP2000.

Un módulo debe poder utilizar el núcleo sin necesitar ningún programa externo.
