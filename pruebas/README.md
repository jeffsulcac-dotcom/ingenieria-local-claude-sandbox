# PRUEBAS

Contiene la validación automática del sistema.

Tipos futuros:
- pruebas unitarias
- integración
- regresión
- CAD
- Revit
- ETABS
- cálculos
- recuperación tras fallos
- comparación de modelos

Regla:

Una tarea no se considera terminada únicamente porque el agente indique PASS.

Debe existir evidencia verificable.
