# MÓDULOS

Contiene herramientas funcionales independientes.

Ejemplos futuros:
- limpieza CAD
- interpretación CAD
- predimensionamiento
- estructuras
- geotecnia
- cimentaciones
- muro de contención
- sanitarias
- eléctricas
- metrados
- presupuesto
- cronograma
- documentación

Regla fundamental:

CADA MÓDULO DEBE PODER FUNCIONAR INDEPENDIENTEMENTE
cuando disponga de sus datos mínimos de entrada.

Los módulos no deben depender directamente de interfaces gráficas ni de n8n.
